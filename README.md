# Quiet Mines · 一局安静的扫雷

米白、鼠尾草绿，留一点空白，认真玩一局扫雷。

原生 HTML / CSS / JavaScript，零依赖、零追踪、无需 API。直接双击 `index.html` 即可离线游玩。

## 功能

- 三种难度：轻松（9×9 / 10 雷）、专注（16×16 / 40 雷）、挑战（30×16 / 99 雷）。
- 首次翻开时才布雷，第一格和八个邻格安全；不保证整盘无需猜测。
- 空白区域自动展开，点击满足插旗数量的数字格可快速展开邻格。
- 右键插旗，触屏长按插旗，独立插旗模式。
- 键盘方向键移动，Enter / 空格翻开，F 插旗，R 重开。
- 浅色 / 深色主题、计时器、分难度最佳纪录（浏览器本地保存）。
- 手机适配；大棋盘可横向滚动，保持格子易于点击。

## 本地使用

下载仓库并打开 `index.html`，或用任意静态文件服务器打开本目录。无需安装依赖。

## 测试

安装 Node.js 后运行：

```sh
npm test
```

`engine.js` 是独立规则引擎，测试覆盖布雷、首次点击保护、边界数字、区域展开、插旗、胜负及快速展开。

## 发布为网页

在 GitHub 仓库 Settings → Pages 中，选择 Deploy from a branch，分支选择 `main`，目录选择 `/ (root)`。部署完成后即可通过 GitHub Pages 链接在线游玩。

## 文件

`index.html`：页面与说明；`style.css`：主题和布局；`engine.js`：游戏规则；`app.js`：交互和存储。
